# RoWeave

Split one Excel sheet into many files and combine many files into one.
Works offline on Windows and Mac. Free beta.

## Download the latest version

- **Windows 10/11 (x64):** [RoWeave-Windows-x64-setup.exe](https://github.com/RoWeave/releases/releases/latest/download/RoWeave-Windows-x64-setup.exe)
- **Mac (Apple Silicon, macOS 12.3+):** [RoWeave-macOS-arm64.dmg](https://github.com/RoWeave/releases/releases/latest/download/RoWeave-macOS-arm64.dmg)

If Windows shows “Windows protected your PC”, click **More info**, then **Run anyway**:
the installer is not signed by Microsoft yet. The Mac app is signed and notarized by Apple.

RoWeave tells you when a new version is out. You can turn the check off in Settings.

This repository holds the installers and update files of the last three versions.
The source code is not public. Questions and bug reports: support@roweave.app
